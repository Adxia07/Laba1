# Практическая работа № 1. Классификация систем реального времени

Консольная программа на Python для классификации задач и системы реального времени (СРВ) и расчёта требуемого времени реакции.

**Вариант:** робот-манипулятор (планирование траектории, управление приводами, обработка датчиков усилия, журналирование).

**Автор:** Субботин А.Д., группа Б.ИВТ.ПРОМ.23.01

## Что делает программа

По набору задач из JSON-файла программа:

- определяет класс системы: жёсткого или мягкого реального времени;
- определяет тип дедлайна каждой задачи: неявный (D = T), ограниченный (D < T) или произвольный (D > T);
- считает запас каждой задачи L = D − C и проверяет выполнимость дедлайна (L ≥ 0);
- находит критическую задачу, то есть жёсткую задачу с наименьшим запасом;
- считает требуемое время реакции R_треб как минимальный дедлайн среди жёстких задач;
- считает коэффициент загрузки U = Σ C/T и проверяет необходимое условие U ≤ 1;
- определяет архитектуру: однопроцессорная, многопроцессорная или распределённая;
- печатает таблицу по задачам и итоговый вывод.

## Требования

- Python 3.10 или новее (в коде используются подсказки типов `list[Task]` и `Task | None`).
- Сторонние библиотеки не нужны: используется только стандартная библиотека (`argparse`, `json`, `sys`, `dataclasses`, `pathlib`), поэтому `pip install` выполнять не требуется.
- Операционная система: Windows, Linux или macOS.
- Файл данных в формате JSON, в кодировке UTF-8 без подписи (BOM).

## Формат входных данных

Файл JSON содержит параметры системы и список задач (время в миллисекундах):

```json
{
  "variant": "Робот-манипулятор",
  "system": {"cpus": 1, "network": false},
  "tasks": [
    {"name": "Обработка датчиков усилия", "hardness": "жёсткое", "C": 1,  "D": 5,   "T": 5},
    {"name": "Управление приводами",      "hardness": "жёсткое", "C": 3,  "D": 10,  "T": 10},
    {"name": "Планирование траектории",   "hardness": "твёрдое", "C": 20, "D": 80,  "T": 100},
    {"name": "Журналирование",            "hardness": "мягкое",  "C": 30, "D": 500, "T": 500}
  ]
}
```

Поле `hardness` принимает значения: `жёсткое`, `твёрдое`, `мягкое`. Файл должен быть в кодировке UTF-8 без подписи (BOM).

## Структура кода

| Функция | Назначение |
|---|---|
| `slack(task)` | запас L = D − C |
| `is_feasible(task)` | выполнимость дедлайна |
| `deadline_type(task)` | тип дедлайна |
| `classify_system(tasks)` | класс системы |
| `critical_task(tasks)` | критическая задача |
| `required_reaction_time(tasks)` | R_треб |
| `utilization(tasks)` | коэффициент загрузки U |
| `classify_architecture(n_cpu, has_network)` | архитектурный класс |
| `load_json(path)` | чтение данных из JSON |

Модель задачи `Task` оформлена через `@dataclass`.
